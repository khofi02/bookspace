## BOOKSPACE – Online Book Store

**BOOKSPACE** adalah aplikasi website toko buku online yang dikembangkan menggunakan React. Website ini dirancang untuk memberikan pengalaman berbelanja buku secara online melalui tampilan yang sederhana, menarik, dan mudah digunakan.

Project ini merupakan pengembangan frontend sebagai bagian dari proses pembelajaran dan penerapan teknologi pengembangan web.

## Fitur Utama

- **Home Page** – Menampilkan halaman utama dan rekomendasi buku.
- **Daftar Buku** – Menampilkan koleksi buku yang tersedia.
- **Detail Buku** – Menampilkan informasi lebih lanjut mengenai buku yang dipilih.
- **Kategori Buku** – Mengelompokkan buku berdasarkan kategori.
- **Shopping Cart** – Menambahkan buku ke keranjang belanja.
- **Pengelolaan Keranjang** – Mengubah jumlah buku dan menghapus item dari keranjang.
- **Checkout** – Mengisi informasi pemesanan dan memilih metode pembayaran.
- **About** – Menampilkan informasi mengenai BOOKSPACE.
- **Contact** – Menyediakan halaman informasi kontak.

## Teknologi yang Digunakan

- **React** – Library JavaScript untuk membangun antarmuka pengguna.
- **Vite** – Build tool dan development server.
- **React Router** – Mengatur navigasi antarhalaman.
- **Bootstrap 5** – Membantu membuat tampilan website.
- **CSS** – Mengatur desain dan tampilan tambahan.

## Cara Menjalankan Project

Pastikan Node.js dan npm sudah terpasang di komputer.

1. Clone repository:
git clone https://github.com/khofi02/bookspace.git


2. Masuk ke folder project:
cd bookspace

3. Install dependencies:
npm install

4. Jalankan aplikasi:
npm run dev

5. Buka alamat lokal yang ditampilkan di terminal, biasanya:
http://localhost:5173

## Catatan Project

BOOKSPACE saat ini merupakan project frontend. Data buku dan proses keranjang belanja dikelola pada sisi aplikasi React.

Fitur checkout masih berupa simulasi antarmuka dan belum terhubung dengan backend, database, maupun payment gateway.
